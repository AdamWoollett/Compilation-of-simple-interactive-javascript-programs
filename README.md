This repository contains 4 small JavaScript projects I created throughout my time learning.

"1) Customisable Image Gallery" is a web page with the functionality for a user to add any images to the page in a gallery if they have a URL for it.

"2) Customisalbe To-Do list using arrays" is a web page where users can add "tasks" to an array and that array gets displayed as a list on the page, with the user able to remove individual tasks at will.

"3) Basic Calculator" is a simple program that can take two numbers and either add, subtract, multiply or divide them depending on what the user selects.

"4) Simple loop of incrementing number each second" runs a looping JavaScript function that increases a number variable by 1 and logs it to the browser console each second.
